# 快速开始 - 5 分钟配置 Claude Code

这个指南帮你快速上手 Claude Code 配置。

---

## 第一步：复制模板

```bash
# 在项目根目录创建 .claude 文件夹
mkdir .claude

# 复制配置模板
cp .claude/settings.json.template .claude/settings.json
cp .claude/CLAUDE.md.template .claude/CLAUDE.md
```

---

## 第二步：修改 settings.json

打开 `.claude/settings.json`，修改以下内容：

### 1. 选择模型

```json
"model": "sonnet"  // 或 "opus[1m]"
```

| 模型 | 特点 | 适用场景 |
|------|------|---------|
| `sonnet` | 速度快，质量高 | 日常开发 |
| `opus[1m]` | 最强，1M 上下文 | 复杂任务 |

### 2. 配置权限

根据你的项目调整 `permissions.allow` 和 `permissions.block`。

```json
"permissions": {
  "allow": [
    "Read(/**)",           // 读取文件
    "Write(./src/**)",     // 写代码到 src
    "Bash(npm *)",         // 运行 npm
    "WebSearch"            // 联网搜索
  ],
  "block": [
    "Bash(rm -rf *)"       // 禁止删除
  ]
}
```

---

## 第三步：修改 CLAUDE.md

打开 `.claude/CLAUDE.md`，填写你的项目信息：

### 1. 替换占位符

把所有 `{{占位符}}` 替换成你自己的内容：

```markdown
# {{项目名称}}  →  # 我的博客项目

## 技术栈
- {{如：React 18}}  →  - React 18
- {{如：TypeScript}} →  - TypeScript 5.5
```

### 2. 至少填写这些内容

- ✅ 项目概述
- ✅ 技术栈
- ✅ 目录结构
- ✅ 编码规范
- ✅ 常用命令

---

## 第四步：重启 Claude Code

配置完成后，重启 Claude Code 使配置生效。

---

## 第五步：测试

在 Claude Code 中说：

```
帮我创建一个按钮组件
```

如果 Claude 生成的代码符合你在 CLAUDE.md 中定义的规范，说明配置成功！

---

## 快速参考

### 配置文件位置

```
项目根目录/
└── .claude/
    ├── settings.json       # 权限配置
    └── CLAUDE.md           # 项目文档
```

### 常见问题

**Q: 配置不生效？**
A: 检查文件位置是否正确，重启 Claude Code

**Q: Claude 不听指令？**
A: 检查 CLAUDE.md 是否写清楚了规范

**Q: 权限被拒绝？**
A: 检查 settings.json 中的 permissions.allow
