# 配置详解

本文档详细解释 Claude Code 的每个配置项。

---

## settings.json 配置详解

### 一、model（模型选择）

```json
"model": "sonnet"
```

| 值 | 说明 |
|---|---|
| `sonnet` | 平衡模型，速度快，适合日常开发 |
| `opus[1m]` | 最强模型，1M 上下文，适合复杂任务 |
| `haiku` | 最快模型，适合简单任务 |

**选择建议**：
- 日常开发 → `sonnet`
- 复杂重构/架构设计 → `opus[1m]`
- 简单修改/格式化 → `haiku`

---

### 二、permissions（权限配置）

权限配置决定了 Claude 能做什么、不能做什么。

#### permissions.allow（允许的操作）

```json
"allow": [
  "Read(/**)",           // 读取任何文件
  "Write(./src/**)",     // 写入到 src 目录
  "Bash(npm *)",         // 运行 npm 命令
  "WebSearch"            // 联网搜索
]
```

**常用权限**：

| 权限 | 说明 |
|---|---|
| `Read(/**)` | 读取任何文件 |
| `Write(./src/**)` | 写入 src 目录 |
| `Write(./components/**)` | 写入 components 目录 |
| `Bash(npm *)` | 运行 npm 命令 |
| `Bash(npx *)` | 运行 npx 命令 |
| `Bash(git status)` | 查看 git 状态 |
| `Bash(git diff)` | 查看 git 差异 |
| `WebSearch` | 联网搜索 |

#### permissions.block（禁止的操作）

```json
"block": [
  "Bash(rm -rf *)",      // 禁止删除
  "Bash(git push --force *)"  // 禁止强制推送
]
```

**安全建议**：
- 禁止删除命令：`Bash(rm -rf *)`
- 禁止强制推送：`Bash(git push --force *)`
- 禁止修改 node_modules：`Write(./node_modules/**)`

---

### 三、env（环境变量）

```json
"env": {
  "CLAUDE_DEFAULT_LANGUAGE": "zh-CN",
  "NODE_ENV": "development"
}
```

**常用环境变量**：

| 变量 | 说明 |
|---|---|
| `CLAUDE_DEFAULT_LANGUAGE` | 默认语言（zh-CN / en） |
| `NODE_ENV` | 环境模式（development / production） |

---

### 四、hooks（自动化钩子）

在特定事件发生时自动执行命令。

#### pre-commit（提交前钩子）

```json
"pre-commit": [
  {
    "name": "代码检查",
    "command": "npm run lint",
    "run": "auto",           // auto = 自动执行
    "fail_on_error": false   // 失败时不阻止提交
  }
]
```

**参数说明**：
- `name`: 钩子名称
- `command`: 要执行的命令
- `run`: `auto`（自动）或 `manual`（手动确认）
- `fail_on_error`: 失败时是否阻止

#### file_change（文件变更钩子）

```json
"file_change": [
  {
    "pattern": "src/**/*.tsx",
    "command": "npx tsc --noEmit"
  }
]
```

---

### 五、mcpServers（MCP 服务器）

MCP = Model Context Protocol，给 Claude 安装"插件"。

#### 基本格式

```json
"mcpServers": {
  "服务器名称": {
    "command": "npx",
    "args": ["包名"],
    "env": {
      "环境变量": "值"
    }
  }
}
```

#### 常用 MCP

**1. Filesystem MCP - 跨项目搜索**

```json
"filesystem": {
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "项目路径"]
}
```

**2. GitHub MCP - 查看 GitHub 代码**

```json
"github": {
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-github"],
  "env": {
    "GITHUB_TOKEN": "你的 Token"
  }
}
```

## CLAUDE.md 配置详解

CLAUDE.md 是项目的"说明书"，Claude 会根据它来理解你的项目。

### 必需内容

#### 1. 项目概述

```markdown
## 项目概述
一句话描述项目是做什么的。
```

#### 2. 技术栈

```markdown
## 技术栈
- React 18 + TypeScript 5.5
- Tailwind CSS + shadcn/ui
```

#### 3. 目录结构

```markdown
## 目录结构
src/
├── components/  # 组件
├── pages/       # 页面
└── utils/       # 工具函数
```

#### 4. 编码规范

```markdown
## 编码规范
1. 使用函数式组件
2. Props 必须定义类型
3. 禁止使用 any
```

### 可选内容

- 命名约定
- Git 工作流
- 常用命令
- 注意事项

---

## 配置优先级

当有多个配置文件时，优先级从高到低：

1. `settings.local.json` - 本地覆盖（不提交 Git）
2. `settings.json` - 项目配置
3. 全局配置（用户目录）

---

## 完整示例

```json
{
  "model": "sonnet",
  "permissions": {
    "allow": [
      "Read(/**)",
      "Write(./src/**)",
      "Bash(npm *)",
      "WebSearch"
    ],
    "block": [
      "Bash(rm -rf *)"
    ]
  },
  "env": {
    "CLAUDE_DEFAULT_LANGUAGE": "zh-CN"
  },
  "hooks": {
    "pre-commit": [
      {
        "name": "代码检查",
        "command": "npm run lint",
        "run": "auto"
      }
    ]
  }
}
```
