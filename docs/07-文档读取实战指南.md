# 文档读取实战指南

本指南教你如何让 Claude 读取和理解各种文档，包括项目文档、公司文档、在线文档。

---

## 文档类型对应表

| 文档类型 | 读取方式 | 推荐技能 |
|---------|---------|---------|
| 项目文档（本地） | 文件路径、拖拽 | read-docs |
| 公司文档（内部系统） | 企业 MCP | read-docs |
| 在线技术文档 | web-reader MCP | read-docs |
| 代码示例 | filesystem MCP | search-docs |
| 长文档 | 分段读取 | summarize-docs |

---

## 场景 1: 读取项目文档

### 需求
Claude 需要了解项目结构、规范、已有的代码。

### 操作步骤

#### Step 1: 读取项目根文档
```
请读取项目的 README.md
查看 ./docs 目录下的文档
```

#### Step 2: 读取技术文档
```
读取 ./docs/架构设计.md
查看 ./docs/API文档.md
```

#### Step 3: 读取代码示例
```
在项目中搜索类似的组件实现
参考 ./components/UserCard.tsx 的风格
```

### 完整对话示例

```
你: 读取项目的 README.md
Claude: [读取并总结项目概况]

你: 读取 ./docs/前端开发规范.md
Claude: [读取并理解编码规范]

你: 根据这些文档，创建一个用户列表组件
Claude: [生成符合规范的组件代码]
```

## 场景 2: 读取公司文档

### 需求
Claude 需要查看公司规范、需求文档、设计文档。

### 操作步骤

#### Step 1: 配置企业 MCP

```json
{
  "mcpServers": {
    "company-wiki": {
      "command": "node",
      "args": ["./mcp-servers/company-wiki/dist/index.js"],
      "env": {
        "WIKI_API_KEY": "${WIKI_API_KEY}"
      }
    }
  }
}
```

#### Step 2: 搜索公司文档
```
搜索 Wiki 上关于"支付模块"的文档
查找公司前端开发规范
```

#### Step 3: 读取具体文档
```
读取 Wiki 上的"用户认证设计"文档
获取 PRD-1234 的需求详情
```

### 完整对话示例

```
你: 从 Jira 获取 FE-5678 需求详情
Claude: [读取需求]

你: 搜索公司 Wiki 上的支付规范
Claude: [搜索并获取规范]

你: 根据需求和规范，设计支付表单组件
Claude: [生成符合规范的组件]
```

## 场景 3: 读取在线文档

### 需求
Claude 需要查阅第三方库文档、API 文档。

### 操作步骤

#### Step 1: 使用 Web Reader
```
用 web-reader 读取 https://react.dev/learn
读取 https://ui.shadcn.com/docs/components/button
```

#### Step 2: 搜索技术文档
```
搜索 React Query 最新文档
查一下 Ant Design Table 组件的用法
```

#### Step 3: 提取代码示例
```
从文档中提取代码示例
把文档中的示例改写成符合项目规范的代码
```

### 完整对话示例

```
你: 用 web-reader 读取 shadcn/ui 的 Button 文档
Claude: [读取文档]

你: 提取文档中的代码示例
Claude: [提取并整理示例]

你: 根据文档，为项目创建一个按钮组件
Claude: [生成符合文档规范的组件]
```

## 场景 4: 组合使用多个文档源

### 需求
Claude 需要综合多个文档源的信息。

### 操作流程

```
1. 读取项目文档 → 了解项目结构
   ↓
2. 搜索代码示例 → 参考现有实现
   ↓
3. 读取公司规范 → 确保符合规范
   ↓
4. 查阅在线文档 → 获取最新技术
   ↓
5. 综合所有信息 → 生成代码
```

### 完整对话示例

```
你: 读取项目的 README 和架构文档
Claude: [读取项目文档]

你: 在项目中搜索列表组件的实现
Claude: [搜索并找到示例]

你: 读取公司 Wiki 上的组件规范
Claude: [读取规范]

你: 用 web-reader 读取 React Hook 最佳实践
Claude: [读取在线文档]

你: 综合以上信息，帮我重构 UserList 组件
Claude: [生成符合所有规范的代码]
```

## 常见问题

### Q1: 文档太长怎么办？

**A:** 分段读取：

```
分段总结这个文档
先读取前半部分，再读取后半部分
只读取与"组件开发"相关的部分
```

### Q2: 文档在内部系统，无法直接访问？

**A:** 配置企业 MCP：

```
配置公司的 Wiki MCP
配置 Jira MCP
配置内部文档系统 MCP
```

### Q3: 如何确保 Claude 按照规范写代码？

**A:** 多文档综合：

```
1. 读取项目规范文档
2. 参考现有代码示例
3. 明确告诉 Claude 遵循规范
```

### Q4: 文档格式不支持怎么办？

**A:** 多种方式尝试：

```
1. 直接拖拽文件到 Claude
2. 复制粘贴内容
3. 转换成支持的格式
4. 使用 MCP 读取
```

## 最佳实践

### ✅ 推荐做法

1. **先读项目文档，再写代码**
```
1. 读取 README.md
2. 读取编码规范
3. 参考代码示例
4. 开始写代码
```

2. **综合多个信息源**
```
项目文档 + 代码示例 + 公司规范 + 在线文档
```

3. **边读边问**
```
读取 → 理解 → 提问 → 确认 → 开发
```

### ❌ 避免做法

1. **不读文档直接写**
```
❌ 帮我写一个用户组件
✅ 先读取项目文档，再写用户组件
```

2. **只看单一信息源**
```
❌ 只看在线文档
✅ 项目文档 + 在线文档 + 代码示例
```

3. **不理解就开写**
```
❌ 直接开始写代码
✅ 先确认理解，再开始写代码
```
