# 项目技术栈与规范

## 技术栈
- **前端框架**: React 18 + TypeScript 5.5
- **样式方案**: Tailwind CSS 3.4 + shadcn/ui
- **状态管理**: Zustand
- **路由**: React Router v6
- **构建工具**: Vite 5
- **代码规范**: ESLint + Prettier
- **HTTP 客户端**: Axios

## 编码规范

### 组件规范
1. 所有组件使用**函数式组件 + TypeScript**
2. **禁止使用 any 类型**，用 unknown 代替
3. 组件文件命名：**PascalCase**（如 UserCard.tsx）
4. 导出使用**默认导出**

### 代码风格
1. 工具函数命名：**camelCase**（如 formatDate.ts）
2. 优先使用 shadcn/ui 组件，不要自己造轮子
3. 组件拆分原则：一个组件只做一件事，**超过 200 行必须拆分**
4. 只注释"为什么"，不注释"做什么"

### 状态管理规范
1. 组件内部状态：useState
2. 跨组件状态：Zustand
3. 服务器状态：使用封装的 request 函数

## 项目结构
```
src/
├── components/      # 通用组件
├── pages/          # 页面组件
├── hooks/          # 自定义 Hooks
├── utils/          # 工具函数
├── stores/         # Zustand 状态
├── lib/            # 第三方库封装
└── types/          # TypeScript 类型定义
```

## 注意事项
- ❌ 不要使用 class 组件
- ❌ 不要使用 Redux
- ❌ 不要用 fetch，用封装的 axios request 函数
- ✅ 所有异步请求统一使用 try/catch + toast 提示
- ✅ 错误处理必须考虑边界情况
